# Resituate — Geotagged Image Cleanup

See <https://resituate.murphy.science> for all the info.

## LLM Usage

This is a vibe-coded project. It's proven to work for me and isn't too complicated using simple web technologies but be aware that I haven't meticulously reviewed everything. I used DeepSeek V4.1 Flash 1017 with OpenCode and paid about 4$ to Replace via openrouter for the inference.

I do feel responsible for and invested in this project though. Please don't feel any need to dig into the generated code yourself and contribute with PRs. An issue is all it needs and I will take care of it. Why did I vibe-code this? This project isn't about the joy of coding for me but mainly about the end result. I simply needed this tool to speed up my workflow of cleaning up sequences of 360° street-level imagery and vibe-coding allowed me to get it with a day of work.
